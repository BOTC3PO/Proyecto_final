## 1. Número de oxidación

Es la carga que "tendría" un átomo si el compuesto fuera 100% iónico —
sale de comparar electronegatividades (ver `../enlace-quimico-polaridad/`).
Reglas básicas:

- Un elemento solo (sin combinar, ej.: O₂, Fe) tiene número de oxidación 0.
- El oxígeno casi siempre es −2 (excepto en peróxidos).
- El hidrógeno casi siempre es +1 (excepto con metales, donde es −1).
- La suma de los números de oxidación de un compuesto neutro da 0.
- Muchos metales tienen **más de un número de oxidación posible** (ej.:
  hierro puede ser +2 o +3) — por eso hace falta indicarlo en el nombre.

## 2. Compuestos binarios metal + no metal (tipo sal, ej.: NaCl, FeCl₃)

Nombre: **"[no metal]uro de [metal]"**. Si el metal tiene un solo número
de oxidación posible, no hace falta aclarar nada más:

```
NaCl  →  cloruro de sodio
```

Si el metal tiene más de un número de oxidación posible, hace falta
especificar cuál (ver sistemas de nombrado, sección 4):

```
FeCl₂  →  cloruro de hierro (II)     [o "cloruro ferroso"]
FeCl₃  →  cloruro de hierro (III)    [o "cloruro férrico"]
```

## 3. Óxidos (metal/no metal + oxígeno)

**Óxido de [elemento]**, con el mismo sistema de aclarar el número de
oxidación cuando hace falta:

```
Na₂O   →  óxido de sodio
Fe₂O₃  →  óxido de hierro (III)   [o "óxido férrico"]
CO₂    →  dióxido de carbono      (con no metales, se usan prefijos, no números romanos)
```

## 4. Los 3 sistemas de nombrado (para el mismo compuesto)

| Sistema | Cómo indica el número de oxidación | Ejemplo (FeCl₃) |
|---|---|---|
| **Stock** (el más usado hoy) | Número romano entre paréntesis | cloruro de hierro (III) |
| **Tradicional** | Sufijo -oso (menor) / -ico (mayor) sobre la raíz latina | cloruro férrico |
| **Sistemática** (con no metales) | Prefijos griegos: mono-, di-, tri-, tetra- | tricloruro de hierro |

**Regla práctica del sistema tradicional**: si el metal tiene 2 números
de oxidación posibles, el menor lleva **-oso** y el mayor **-ico** (a
veces sobre la raíz latina del elemento: hierro→ferr-, cobre→cupr-,
oro→aur-, plata→argént-).
