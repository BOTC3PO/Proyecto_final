# Resolución de Problemas — Identificar Alternativas (teoría)

> Tema del MAPA: `resolucion-problemas/identificar-alternativas`. Depende de definir problema (ver `../dependencias.md`).

## Tipo de teoría (si esto se carga al sistema)

**Presentación** — El proceso de reconocer múltiples opciones para resolver un problema.

---

## 1. Definición de alternativas

Identificar alternativas es el acto de explorar distintas maneras de abordar una situación, reconociendo que no hay un único camino válido para llegar a una solución. Este paso se basa en la premisa de que cualquier problema puede tener varias opciones, y cada una tiene ventajas y limitaciones propias. Por ejemplo, si el desafío es mejorar la comunicación en un equipo de trabajo, las alternativas podrían incluir talleres de habilidades blandas, reuniones más frecuentes o herramientas digitales para facilitar el intercambio de ideas.

El objetivo principal de este proceso no es encontrar una respuesta "correcta", sino ampliar el horizonte de posibilidades. Esto permite elegir la opción que mejor se adapte al contexto, recursos disponibles y objetivos específicos del problema.

---

## 2. La multiplicidad de soluciones

Un error común en la resolución de problemas es creer que existe solo una solución válida. Sin embargo, en la práctica, casi todos los desafíos admiten múltiples caminos. Esto no significa que todas las alternativas sean igualmente efectivas; lo que importa es haberlas considerado para tomar una decisión informada.

Por ejemplo, al enfrentar un problema de contaminación ambiental, las alternativas podrían variar desde políticas públicas estrictas hasta campañas educativas o incentivos económicos para empresas. Cada enfoque tiene implicaciones distintas: una política podría ser más eficiente a largo plazo, pero más difícil de implementar; una campaña educativa es accesible pero su impacto puede tardar en notarse.

Identificar estas alternativas requiere abrir la mente a soluciones que no estén dentro del "caja negra" de lo convencional. Es aquí donde entra en juego el pensamiento creativo, ya que muchas veces las mejores ideas surgen al mirar un problema desde ángulos inesperados.

---

## 3. Pensamiento divergente

El proceso de identificar alternativas está estrechamente relacionado con el **pensamiento divergente**, una forma de razonamiento que busca generar múltiples ideas o soluciones en lugar de enfocarse en un solo camino. Este tipo de pensamiento es clave cuando se trabaja con problemas complejos, como conflictos interpersonales o desafíos sociales.

Por ejemplo, si el problema es la baja productividad en una empresa, el pensamiento divergente podría proponer alternativas como: reorganizar horarios laborales, implementar sistemas de reconocimiento del trabajo, mejorar las herramientas tecnológicas disponibles o incluso revisar los objetivos establecidos. Cada opción requiere análisis, pero la diversidad de ideas es lo que permite elegir la más adecuada.

Este enfoque contrasta con el **pensamiento convergente**, que se centra en reducir opciones para llegar a una solución única. Mientras el pensamiento divergente es útil en etapas iniciales (para generar alternativas), el convergente se aplica después, cuando se evalúan y seleccionan las mejores propuestas.

---

## 4. Herramientas para explorar alternativas

Existen diversas técnicas que facilitan la identificación de alternativas. Entre ellas destacan:

- **Brainstorming**: Sesión grupal donde se generan ideas sin juzgarlas inicialmente.
- **Análisis de escenarios**: Considerar cómo el problema podría resolverse en distintos contextos o condiciones.
- **Mapas mentales**: Representaciones visuales que conectan un problema con posibles soluciones.
- **Listas de preguntas**: Como "¿Qué pasaría si...?", "¿Hay otro modo de lograr esto?".

Estas herramientas no garantizan una solución perfecta, pero ayudan a evitar la rigidez mental y a explorar caminos que de otra manera podrían quedar ocultos. Por ejemplo, en un conflicto entre estudiantes por recursos compartidos, una lista de preguntas podría revelar alternativas como turnos rotativos, sistemas de préstamo o incluso redistribución de materiales.
