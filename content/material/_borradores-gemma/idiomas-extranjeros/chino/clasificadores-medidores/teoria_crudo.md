# Clasificadores-medidores en chino (HSK1)  

## Introducción  
Los clasificadores o medidores son palabras que se usan junto con números para contar objetos, personas o conceptos en chino. En el nivel HSK1, su aprendizaje es fundamental, ya que permiten expresar cantidades de manera precisa y natural. A diferencia del español, donde no se requieren clasificadores, en chino es obligatorio usarlos al mencionar un número seguido de un sustantivo. Por ejemplo, para decir "dos libros", se dice **两本书** (liǎng běn shū), donde **本** (běn) es el clasificador que corresponde a "libro".  

## Explicación central  
Los clasificadores en chino funcionan como complementos de los números y adaptan su forma según el tipo de objeto que se cuente. Algunos ejemplos comunes son:  
- **个** (gè): Se usa para objetos generales o cuando no hay un clasificador específico, como "un coche" (**一辆车** / yī liàng chē; pero aquí se usa **辆** [liàng] para vehículos).  
- **本** (běn): Para libros, revistas o documentos. Ejemplo: **三本书** (sān běn shū) = "tres libros".  
- **条** (tiáo): Para objetos alargados o animales en ciertos contextos. Ejemplo: **两条鱼** (liǎng tiáo yú) = "dos peces".  
- **张** (zhāng): Para papel, cartas o imágenes. Ejemplo: **一张照片** (yī zhāng zhàopiàn) = "una foto".  

Los clasificadores no son intercambiables; usar uno incorrecto puede generar ambigüedad o sonar forzado. Por ejemplo, decir **三本鱼** (sān běn yú) sería gramaticalmente incorrecto, ya que **本** se usa para objetos como libros, no para peces.  

## Errores comunes de hispanohablantes  
1. **Olvidar el clasificador**: A veces se omite por influencia del español. Por ejemplo, decir "dos manzanas" como **两个苹果** (liǎng gè píngguǒ) es correcto, pero si se dice **二苹果** (èr píngguǒ), falta el clasificador **个**.  
2. **Usar el mismo clasificador para todo**: En español, se diría "dos coches" o "dos libros", pero en chino, **辆** (liàng) y **本** (běn) son obligatorios según el objeto. Usar **辆** para un libro sería incorrecto.  
3. **Confusión entre clasificadores**: Algunos clasificadores tienen reglas específicas. Por ejemplo, **个** puede usarse como "general", pero no siempre es el más natural: **一只猫** (yī zhī māo) = "un gato" (usando **只** [zhī] para animales).  

## Comparación con el español  
En español, los números van directamente seguidos de sustantivos sin necesidad de clasificadores. Por ejemplo: "dos libros", "tres coches". En chino, esta estructura no es posible: se requiere un número + clasificador + sustantivo (**三本书** / sān běn shū). Esta diferencia exige que los hispanohablantes adapten su forma de contar, evitando la omisión del clasificador.  

## Ejemplo extendido en contexto  
**Contexto**: En una tienda de ropa, un cliente pregunta por camisetas.  
- **Cliente**: 请问，有五件红色的T恤吗？(Qǐngwèn, yǒu wǔ jiàn hóngsè de T xù ma?) = "¿Tienen cinco camisetas rojas?"  
- **Vendedor**: 对不起，我们只有三件。您要买吗？(Duìbùqǐ, wǒmen zhǐyǒu sān jiàn. Nín yào mǎi ma?) = "Lo siento, solo tenemos tres. ¿Quiere comprarlas?"  

En este diálogo, **件** (jiàn) es el clasificador para ropa (camisetas, pantalones), mientras que **个** se usaría para objetos más generales (**一个包** / yī gè bāo = "una bolsa"). El uso correcto de **件** permite una comunicación clara y natural.
