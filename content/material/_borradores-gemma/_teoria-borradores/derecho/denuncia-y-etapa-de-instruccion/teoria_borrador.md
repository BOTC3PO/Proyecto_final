# Derecho — Denuncia y etapa de instrucción (teoría)

> Tema del MAPA: `denuncia_y_etapa_de_instruccion`. Depende de `../inicio_del_proceso_penal/` (ver `../dependencias.md`).

## Tipo de teoría (si esto se carga al sistema)

**Presentación** — Explica cómo comienza un proceso penal y qué sucede durante la investigación judicial.

---

## 1. La denuncia: inicio del proceso

La **denuncia** es el acto mediante el cual una persona (victima, testigo o incluso un ciudadano común) informa a las autoridades sobre un hecho que podría constituir un delito. Es el primer paso para que el sistema judicial intervenga y comience la investigación. Para ser válida, debe contener elementos básicos: el nombre de quien denuncia, una descripción del hecho supuestamente delictivo, y datos suficientes para iniciar una pesquisa (como lugar, tiempo o identidad posible del responsable). La denuncia no es un acusación formal, sino una notificación que activa la acción de la justicia.

## 2. Objetivos de la etapa de instrucción

Una vez recibida la denuncia, se inicia la **etapa de instrucción**, cuyo propósito principal no es decidir si hay culpabilidad, sino investigar para descubrir la verdad real del hecho. Durante esta fase, el juez o el fiscal (según la estructura judicial) ordenan medidas que permitan recolectar pruebas: testimonios, documentos, peritajes técnicos, allanamientos de domicilio, entre otros. El objetivo es construir un cuerpo de evidencia sólido para determinar si hay elementos suficientes como para acusar a alguien en juicio.

## 3. Medios de prueba clave

En la instrucción, se usan diversos **medios de prueba** para esclarecer los hechos. Por ejemplo:  
- El **testimonio** de personas que presenciaron el hecho o tienen conocimiento relevante.  
- La **pericia**, donde un experto analiza evidencias físicas (como huellas, ADN o documentos) para aportar una opinión técnica.  
- Los **allanamientos**, para incautar objetos relacionados con el delito.  
Estos medios deben cumplir con reglas de legalidad y respeto a los derechos de las partes involucradas.

## 4. Rol del fiscal y el juez

El **fiscal** es quien lidera la investigación durante la instrucción, solicitando al juez las medidas necesarias para obtener pruebas. El juez, por su parte, supervisa que todo se haga conforme a derecho: si un allanamiento es ilegal o una prueba fue obtenida sin seguir protocolos, puede ser descartada. Juntos, deciden si el caso tiene **mérito** (es decir, si hay suficiente evidencia para pasar a juicio). Si no lo hay, se archiva la causa.
