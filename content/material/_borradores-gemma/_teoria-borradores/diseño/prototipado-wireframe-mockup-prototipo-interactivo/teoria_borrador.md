# Diseño — Prototipado: wireframe, mockup y prototipo interactivo (teoría)

> Tema del MAPA: `PROT-03`. Depende de: `../flujo_de_trabajo/` (ver `../dependencias.md`).

## Tipo de teoría

**Presentación** — Explicación de las etapas del prototipado en el proceso de diseño digital.

---

## 1. ¿Qué es un wireframe y para qué sirve?

Un **wireframe** es la estructura básica de una interfaz, como un boceto sin detalles visuales. Muestra cómo se organizan los elementos principales (botones, menús, textos) en la pantalla, pero no incluye colores ni imágenes. Su objetivo es definir la **jerarquía de información** y el **flujo de navegación**, asegurando que el usuario encuentre lo que busca sin distracciones.

Por ejemplo: si estás diseñando una app de compras online, el wireframe mostrará dónde va el buscador, los filtros por categoría y la ubicación del carrito. No importa cómo se ve: lo clave es que funcione bien. [IMAGEN: Wireframe de una página web con elementos en blanco y negro]

## 2. De wireframe a mockup: ¿dónde entra el diseño visual?

Una vez que la estructura está clara, se pasa al **mockup**, que es un paso más cercano al producto final. Aquí se añaden colores, tipografías, imágenes y otros elementos visuales para darle forma estética a la interfaz. El mockup no simula interacciones, pero deja claro cómo será el aspecto final del diseño.

La diferencia clave con el wireframe es que el mockup **no permite hacer clic ni probar flujos**, solo muestra cómo se verá una pantalla terminada. Por eso se usa para validar decisiones de estilo antes de programar. [IMAGEN: Comparación entre un wireframe y un mockup de la misma interfaz]

## 3. El prototipo interactivo: cuando el diseño "se pone en movimiento"

El **prototipo interactivo** es una versión avanzada que simula cómo funciona la app o sitio web. Permite hacer clic en botones, navegar entre pantallas y ver transiciones. No está hecho con código real, pero reproduce las acciones del usuario para probar si el flujo de navegación es intuitivo.

Este paso es crucial para detectar problemas de **experiencia de usuario (UX)**: ¿el usuario se pierde en la navegación? ¿los botones son difíciles de encontrar? El prototipo interactivo responde a estas preguntas sin necesidad de construir el producto completo. [IMAGEN: Flujo de un prototipo interactivo con animaciones]

## 4. Ventajas y límites de cada etapa

Cada nivel tiene su propósito:
- **Wireframe**: Rapidez en la planificación estructural.
- **Mockup**: Validación visual sin comprometer recursos.
- **Prototipo interactivo**: Prueba real del comportamiento del usuario.

Sin embargo, no se usan por separado. Un buen diseño digital pasa por todas las etapas: primero se define el esqueleto (wireframe), luego se le da forma con colores y gráficos (mockup) y finalmente se prueba su interactividad (prototipo interactivo).

## 5. Herramientas comunes para cada fase

- **Wireframes**: Se pueden hacer con herramientas como Figma, Balsamiq o incluso en papel.
- **Mockups**: Figma, Adobe XD o Sketch son populares para crear diseños visuales.
- **Prototipos interactivos**: Figma y Axure permiten agregar interacciones y simular comportamientos.
