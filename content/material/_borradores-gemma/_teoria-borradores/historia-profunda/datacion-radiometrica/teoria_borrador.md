# Historia Profunda — Datación Radiométrica (teoría)

> Tema del MAPA: `datacion_radiometrica`. Depende de: a determinar (ver dependencias.md).

## Tipo de teoría (si esto se carga al sistema)

**Presentación** — Explicación del método científico para calcular la edad de materiales orgánicos o rocosos usando desintegración radiactiva.

---

## 1. Concepto de vida media

La **vida media** es el tiempo que tarda la mitad de los átomos de un isótopo radiactivo en descomponerse naturalmente. Por ejemplo, si se tiene una muestra de carbono-14 con 100 gramos al inicio, después de su vida media (5730 años), quedarán 50 gramos. Este valor no cambia: es constante para cada isótopo y lo hace útil para datar materiales en la Tierra. ## 2. Cómo se calcula el isótopo remanente

Cada vez que pasa una vida media, la cantidad restante es siempre la mitad de lo que había antes. Si se tienen dos vidas medias, quedarán 25% del original (0,25). Tres vidas medias: 12,5% (0,125), y así sucesivamente. Esto funciona para cualquier isótopo, como el potasio-40 o el uranio-238, que tienen vidas medias muy largas. Por eso, para rocas antiguas se usan isótopos con vidas medias de miles de millones de años.

## 3. Aplicación en la datación

Para datar una muestra, se mide la proporción entre el isótopo radiactivo y su producto de desintegración (como el carbono-14 y el nitrógeno-14). Si se sabe cuántas vidas medias han transcurrido, se calcula el tiempo total. Por ejemplo: si una muestra tiene 25% del isótopo original, eso significa que pasaron dos vidas medias (si la vida media es de 5730 años, la edad sería 11.460 años).

## 4. Cálculo matemático básico

El cálculo se basa en una fórmula exponencial:  
**N = N₀ × (½)ⁿ**, donde:  
- *N* es el isótopo restante,  
- *N₀* es la cantidad original,  
- *n* es el número de vidas medias transcurridas.  

Para encontrar *n*, se usa logaritmo:  
**log₂(N/N₀) = –n**.  
Por ejemplo, si queda 10% del isótopo (N/N₀ = 0,1), se calcula que pasaron alrededor de 3,32 vidas medias.
