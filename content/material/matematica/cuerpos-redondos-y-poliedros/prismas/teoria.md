## Qué es un prisma

Un **prisma** es un poliedro (cuerpo con caras planas) formado por dos
bases poligonales **congruentes y paralelas**, unidas por caras laterales
que son rectángulos (en un prisma **recto**, el que se ve en este
módulo). El prisma rectangular (una caja) del módulo anterior
(`../../volumen-y-capacidad/`) es sólo UN caso particular: en general, la
base de un prisma puede ser cualquier polígono — un triángulo, un
pentágono, un hexágono.

## Elementos de un prisma

- **Bases**: las dos caras poligonales, iguales y paralelas entre sí.
- **Caras laterales**: los rectángulos que conectan los lados
  correspondientes de las dos bases. Un prisma con base de n lados tiene
  exactamente n caras laterales.
- **Altura**: la distancia perpendicular entre las dos bases.
- **Aristas y vértices**: los bordes y las esquinas del cuerpo.

## Cómo se nombra un prisma

Un prisma se nombra según la forma de su base: **prisma triangular**
(base triángulo), **prisma rectangular** (base rectángulo — la caja ya
vista), **prisma pentagonal** (base pentágono), **prisma hexagonal** (base
hexágono), etc.

## Fórmula general del volumen

Sin importar la forma de la base, el volumen de cualquier prisma recto
se calcula igual:

**V = Área de la base × altura**

Es la misma idea que ya se usó para el prisma rectangular (donde "área de
la base" era largo × ancho), generalizada a cualquier polígono: si la
base es un triángulo, se usa el área del triángulo (ver
`../../perimetro-y-area/`); si es un trapecio, el área del trapecio; y
así con cualquier forma.

## Cantidad de caras, aristas y vértices

Para un prisma cuya base tiene **n** lados:

- Caras: n caras laterales + 2 bases = **n + 2**
- Vértices: n vértices en cada base = **2n**
- Aristas: n aristas en cada base + n aristas laterales = **3n**

Estos tres números cumplen siempre la **fórmula de Euler** de los
poliedros convexos: **Vértices − Aristas + Caras = 2**. Para un prisma:
2n − 3n + (n+2) = 2, se cumple para cualquier n.

## El cubo, otra vez

El cubo (y el prisma rectangular en general) siguen siendo prismas: son
el caso particular donde la base es un cuadrado (o un rectángulo). Todo lo
visto acá — fórmula general, elementos — se aplica igual, sólo que con una
base tan simple que "área de la base" ya se simplificaba a largo × ancho.
