## ¿Qué son las licencias de software y por qué importan?

Las licencias de software son, en esencia, los "términos y condiciones" que definen qué se puede y qué no se puede hacer con un programa informático una vez que lo has obtenido. No basta con descargar o comprar un software; la licencia es el contrato legal que acompaña al código y establece los derechos del usuario y las obligaciones del creador. En la era digital, entender esto es fundamental porque determina si puedes modificar el programa, compartirlo con amigos, usarlo en una empresa o incluso venderlo. Sin una licencia clara, por defecto, todos los derechos están reservados al autor original, lo que significa que técnicamente no podrías hacer nada con ese software más allá de verlo o ejecutarlo, según la ley de propiedad intelectual vigente.

La importancia de distinguir entre los tipos de licencias radica en la ética del software y en la colaboración tecnológica. Argentina, como muchos países, tiene una fuerte comunidad de desarrollo de software libre. Entender estas diferencias te permite tomar decisiones informadas: ¿quieres usar un programa que no te deja ver cómo funciona por dentro? ¿Prefieres colaborar en un proyecto que todos pueden mejorar? ¿Necesitas usar imágenes o textos para tu trabajo escolar? La licencia dicta la cultura de uso: desde el secreto comercial hasta la apertura total.

## Software propietario y de código abierto

El software propietario, también conocido como *software privativo*, es aquel cuyo código fuente (las instrucciones que hacen que el programa funcione) está cerrado y es propiedad exclusiva de su creador o empresa. Ejemplos comunes son Microsoft Windows, macOS o Adobe Photoshop. Bajo esta licencia, generalmente puedes usar el programa para tus fines personales o comerciales, pero no tienes permiso para estudiar cómo está hecho, modificarlo ni redistribuirlo. La empresa mantiene el control total sobre las actualizaciones y la seguridad, y tú dependes de ellos para cualquier cambio.

Por otro lado, el software libre o de código abierto (*open source*) permite que cualquiera acceda al código fuente. Esto no significa necesariamente que sea gratis, sino que es "libre" en el sentido de libertad de uso. Aquí entramos en dos subcategorías importantes: la licencia libre y la permisiva. Las licencias libres, como la GPL (General Public License), tienen una característica clave llamada "copyleft": si modificas el programa y lo distribuyes, debes hacerlo bajo la misma licencia, garantizando que las mejoras también queden abiertas para la comunidad. Es una forma de proteger la libertad del software para siempre.

## Licencias permisivas y Creative Commons

Las licencias permisivas, como la MIT o la Apache, también permiten el acceso al código fuente, pero son mucho más flexibles que las copyleft. Permiten que el código se modifique y se incluya en software propietario sin la obligación de liberar las modificaciones. Esto las hace muy populares en la industria comercial, ya que fomentan la adopción masiva sin imponer restricciones estrictas sobre cómo se usa el resultado final.

Es crucial no confundir las licencias de software con las licencias Creative Commons (CC). Mientras que las primeras regulan el código informático, las CC se utilizan para obras creativas como textos, imágenes, música, videos y diseños. Por ejemplo, si buscas una foto para tu presentación escolar, es vital verificar si tiene una licencia CC que permita el uso comercial o si requiere atribución (dar crédito al autor). Existen varios niveles, desde CC BY (solo pide crédito) hasta CC BY-NC-ND (no permite cambios ni uso comercial). Usar material con licencia CC correctamente evita problemas de derechos de autor y fomenta la cultura de compartir conocimiento de manera responsable.

## Aplicación práctica en tu vida escolar

Imagina que estás haciendo un proyecto de historia y necesitas usar un mapa generado por inteligencia artificial o una fotografía de internet. Lo primero que debes hacer es buscar la licencia de ese recurso. Si usas un programa como LibreOffice en lugar de uno propietario, estás eligiendo software libre, lo que significa que estás apoyando un ecosistema donde el código es transparente y mejorable por cualquier persona del mundo.

Para tus trabajos prácticos, siempre verifica si el material que descargas permite su redistribución. Si encuentras una imagen con licencia CC BY, puedes usarla en tu presentación, pero debes citar al autor original. Si usas código de ejemplo para tu tarea de informática, asegúrate de incluir el aviso de licencia correspondiente si el código original lo exige. Esta práctica no solo es correcta legalmente, sino que te prepara para el entorno profesional, donde la gestión de licencias y la ética digital son competencias esenciales para cualquier desarrollador o usuario de tecnología.
