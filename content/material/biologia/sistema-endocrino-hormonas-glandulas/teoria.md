# Biología — Sistema endocrino: hormonas y glándulas (teoria)

> Tema del MAPA: `BKE`. Depende de `../sistemas-cuerpo-humano/` (ver
> `../dependencias.md`). Prerrequisito de
> `../../../ed-fisica/prevencion-adicciones-ley-26586/` y
> `../../esi/anatomia-y-pubertad/`.

## Tipo de teoría (si esto se carga al sistema)

**Presentación** — glándulas + hormonas principales + comparación con
el sistema nervioso.

---

## 1. Qué es el sistema endocrino

El **sistema endocrino** es el conjunto de **glándulas** que producen
y liberan **hormonas** directamente al torrente sanguíneo, para
regular funciones del cuerpo a distancia — a diferencia del sistema
nervioso (que manda señales eléctricas por nervios, casi
instantáneas), el sistema endocrino manda **mensajes químicos** por la
sangre, más lentos pero de efecto más prolongado.

## 2. Cómo funciona una hormona

Una **hormona** es una molécula mensajera liberada por una glándula
que viaja por la sangre hasta llegar a células de **todo el cuerpo**,
pero sólo actúa sobre las que tienen el **receptor** específico para
esa hormona — el mismo principio de especificidad que la relación
enzima-sustrato (`../enzimas-proteina-sustrato-ph/`): la hormona
"encaja" sólo en las células que tienen el receptor correspondiente,
ignorando el resto.

## 3. Glándulas principales y sus hormonas

| Glándula | Hormona(s) principal(es) | Función |
|---|---|---|
| Hipófisis (pituitaria) | Varias (regula a las demás glándulas) | "Glándula maestra" — coordina al resto del sistema |
| Tiroides | Tiroxina | Regula el metabolismo (velocidad con que el cuerpo usa energía) |
| Páncreas | Insulina, glucagón | Regulan el nivel de glucosa (azúcar) en sangre |
| Suprarrenales | Adrenalina, cortisol | Respuesta al estrés ("lucha o huida") |
| Gónadas (testículos/ovarios) | Testosterona, estrógeno/progesterona | Desarrollo sexual y reproducción — ver `../../esi/anatomia-y-pubertad/` |

## 4. La hipófisis: la "glándula maestra"

La **hipófisis** es especial porque no sólo produce sus propias
hormonas — también libera hormonas que le indican a **otras
glándulas** cuánto producir. Por eso se la llama la glándula maestra
del sistema endocrino: coordina al resto.

## 5. Retroalimentación negativa: cómo el cuerpo se autorregula

El sistema endocrino funciona con **retroalimentación negativa**: si
el nivel de una hormona (o lo que esa hormona regula, como la glucosa
en sangre) sube demasiado, el cuerpo detecta el exceso y reduce la
producción de esa hormona — y viceversa si baja demasiado. Es el mismo
principio que un termostato: el sistema se autocorrige para mantenerse
cerca de un punto de equilibrio (homeostasis, ver
`../sistemas-cuerpo-humano/`).

Ejemplo concreto: cuando la glucosa en sangre sube (después de comer),
el páncreas libera insulina para bajarla; cuando la glucosa baja
demasiado, el páncreas libera glucagón para subirla — un balance
constante, no un valor fijo.

## 6. Conexión con lo que sigue

El sistema endocrino es la base biológica de dos temas que dependen de
él: `../../esi/anatomia-y-pubertad/` (las hormonas sexuales son las
que disparan los cambios de la pubertad) y
`../../../ed-fisica/prevencion-adicciones-ley-26586/` (las sustancias
adictivas interfieren directamente con el sistema de recompensa
hormonal/neuroquímico del cuerpo).
