# Biología — Sistemas del cuerpo humano (teoria)

> Tema del MAPA: `BK`. Depende de `../celula-organelas/` (ver
> `../dependencias.md`).

## Tipo de teoría (si esto se carga al sistema)

**Presentación** — niveles de organización + tabla de sistemas
principales.

---

## 1. Niveles de organización (de lo chico a lo grande)

```
Célula → Tejido → Órgano → Sistema → Organismo
```

- **Célula**: la unidad básica (ver `../celula-organelas/`).
- **Tejido**: grupo de células **similares** que cumplen la misma
  función (ej.: tejido muscular).
- **Órgano**: combinación de **distintos** tejidos que trabajan juntos
  con un propósito (ej.: el corazón, con tejido muscular, nervioso y
  conectivo).
- **Sistema**: conjunto de **órganos** que colaboran en una función
  general del cuerpo.
- **Organismo**: el conjunto de todos los sistemas trabajando juntos —
  la persona completa.

## 2. Los sistemas principales

| Sistema | Función principal | Órganos clave |
|---|---|---|
| Digestivo | Descomponer alimento, absorber nutrientes | Estómago, intestinos, hígado |
| Respiratorio | Intercambio de gases (O₂↔CO₂) | Pulmones, tráquea |
| Circulatorio | Transportar sangre, nutrientes, gases | Corazón, vasos sanguíneos |
| Nervioso | Recibir y procesar información, controlar el cuerpo | Cerebro, médula espinal, nervios |
| Endocrino | Regular funciones con hormonas | Tiroides, páncreas, glándulas |
| Excretor | Filtrar y eliminar desechos | Riñones, vejiga |
| Óseo | Sostén y protección | Huesos |
| Muscular | Movimiento | Músculos |
| Inmunitario | Defensa contra patógenos | Ver `../microbiologia-virus-inmunitario/` |
| Reproductor | Producir descendencia | Órganos reproductivos |

## 3. Los sistemas no funcionan aislados

Ningún sistema trabaja solo: por ejemplo, para que un músculo se mueva
(sistema muscular) hace falta que el sistema **nervioso** mande la
señal, el sistema **circulatorio** traiga oxígeno y glucosa, y el
sistema **respiratorio** haya capturado ese oxígeno del aire — todos
los sistemas están **integrados**, la especialización no significa
independencia.

## 4. Homeostasis: el objetivo compartido de todos los sistemas

Todos los sistemas, en conjunto, mantienen la **homeostasis** (ver
`../ser-vivo-caracteristicas/`) — el equilibrio interno del cuerpo
(temperatura, pH, nivel de azúcar en sangre, etc.) — aunque el ambiente
externo cambie.
