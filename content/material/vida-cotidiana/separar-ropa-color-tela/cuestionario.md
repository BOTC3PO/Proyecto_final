  pasaron por muchos lavados.

### 4 — La prueba de solidez del color

```

tipo: mc
opciones_explicitas:
  - "Mojar una esquina no visible y frotarla con un paño blanco, para ver si el paño se tiñe"
  - "Dejarla al sol un día entero antes de lavarla"
  - "Lavarla siempre junto con ropa blanca para \"probar\" si tiñe"
respuesta: "Mojar una esquina no visible y frotarla con un paño blanco, para ver si el paño se tiñe"

explicacion: |
  Si el paño se tiñe, la prenda todavía suelta color y conviene lavarla
  sola varias veces más.
```

### 6 — Por qué separar por tipo de tela

```

  tags: ["separar_ropa", "vocabulario"]

enunciado: "Además del color, ¿por qué conviene separar la ropa por tipo de tela antes de lavar?"
tipo: mc
opciones_explicitas:
  - "Telas pesadas pueden soltar pelusa que se pega a telas delicadas, y distintas telas necesitan distinto ciclo"
  - "Porque cada tela necesita un detergente de una marca distinta"
  - "Porque la lavadora pesa distinto según la tela y eso rompe el motor"
respuesta: "Telas pesadas pueden soltar pelusa que se pega a telas delicadas, y distintas telas necesitan distinto ciclo"

explicacion: |
  Son dos razones distintas, además del color, para separar antes de
  lavar.
```
