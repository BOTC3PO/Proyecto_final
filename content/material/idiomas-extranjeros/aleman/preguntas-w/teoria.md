## Introducción
Las **W-Fragen** son las preguntas con palabra interrogativa, casi todas empiezan con *W*. En ellas, el **verbo va en segunda posición**: ***Wo wohnst** du?*

## Explicación central
### Palabras interrogativas
| | |
|---|---|
| **wer** | quién (nominativo) |
| **wen** | a quién (acusativo) |
| **wem** | a quién (dativo) |
| **wessen** | de quién |
| **was** | qué |
| **wo** | dónde |
| **woher** | de dónde |
| **wohin** | adónde |
| **wann** | cuándo |
| **warum / wieso** | por qué (respuesta: *weil*) |
| **wie** | cómo |
| **wie viel / wie viele** | cuánto / cuántos |
| **wie lange** | cuánto tiempo |
| **welcher / welche / welches** | cuál (concuerda) |
| **was für ein** | qué tipo de |

### Orden
*W-palabra + verbo + sujeto + resto*: ***Wann fängt** der Film **an**?*

### wo / woher / wohin
- ***Wo** wohnst du? — **In** Berlin.* (lugar)
- ***Woher** kommst du? — **Aus** Spanien.* (origen)
- ***Wohin** fährst du? — **Nach** Italien.* (dirección)

### Preguntas sí/no
Sin palabra W, el verbo va **primero**: ***Kommst** du mit?*

### Wie + adjetivo
*Wie **alt** bist du? Wie **spät** ist es? Wie **groß** ist er? Wie **oft**?*

## Errores comunes de hispanohablantes
1. ❌ *Wo du wohnst?* ✅ *Wo wohnst du?*
2. Confundir *wo* (dónde) con *wer* (quién) y *wohin* (adónde).
3. ❌ *Wie viel Geschwister* ✅ *Wie viele Geschwister* (contable plural).
4. ❌ *Wer siehst du?* ✅ *Wen siehst du?*

## Comparación con el español
El español distingue «dónde, de dónde, adónde» con preposiciones; el alemán usa tres palabras (*wo, woher, wohin*). Y *wer* (quién) suena como el inglés *where* (dónde): ¡ojo!

## Ejemplo extendido en contexto
*— Hallo! **Wie** heißt du? — Ich heiße Tom. — **Woher** kommst du? — Aus Österreich. — **Wo** wohnst du jetzt? — In München. — **Was** machst du hier? — Ich studiere. — **Wie lange** bleibst du? — Zwei Jahre.*
