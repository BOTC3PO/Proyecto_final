# El presente (mudāriʿ) del verbo árabe (nivel A2)

## Introducción
El árabe conjuga el verbo con **prefijos y sufijos** sobre la raíz. El presente (**mudāriʿ**) expresa acciones habituales o en curso, y con el prefijo **سـ** o la partícula **سوف** forma el futuro. Aquí se usa el verbo كتب (ك-ت-ب, escribir) como modelo.

## Explicación central
| Persona | Forma | Traducción |
|---|---|---|
| أنا | **أ**كتب | escribo |
| أنتَ | **ت**كتب | escribes (m.) |
| أنتِ | **ت**كتب**ين** | escribes (f.) |
| هو | **ي**كتب | escribe (él) |
| هي | **ت**كتب | escribe (ella) |
| نحن | **ن**كتب | escribimos |
| أنتم | **ت**كتب**ون** | escriben (ustedes m.) |
| أنتنّ | **ت**كتب**ن** | escriben (ustedes f.) |
| هم | **ي**كتب**ون** | escriben (ellos) |
| هنّ | **ي**كتب**ن** | escriben (ellas) |
| أنتما / هما | **ت / ي**كتب**ان** | (dual) |

- **Prefijos**: أ (yo), ن (nosotros), ت (tú, ella), ي (él, ellos).
- **Sufijos**: ـين (tú f.), ـون (ellos / ustedes m.), ـن (ellas / ustedes f.), ـان (dual).
- **Vocal de la raíz**: cada verbo tiene su vocal (يكتُب *yaktubu*, يذهَب *yadhhabu*, يشرَب *yashrabu*, يقرَأ *yaqraʾu*); se aprende con el diccionario.
- **Ejemplos**: أنا أسكن في مدريد, هو يقرأ الكتاب, هي تشرب الماء, نحن نذهب إلى المدرسة.
- **Negación**: لا + presente: لا أكتب.
- **Futuro**: سـ + presente: سأكتب; o سوف أكتب.

## Errores comunes de hispanohablantes
1. **Confundir ت** (tú / ella): hace falta el pronombre o el contexto.
2. **Olvidar los sufijos** de plural y femenino.
3. **Usar una vocal de raíz incorrecta**.
4. **Usar ما o ليس** para negar el presente en lugar de لا.

## Comparación con el español
El español cambia la terminación del verbo (*escribo, escribes*); el árabe combina un prefijo y a veces un sufijo (أكتب، تكتبين). Ambos permiten omitir el pronombre, pero el género de la 2.ª y 3.ª persona solo se ve en la forma árabe.

## Ejemplo extendido en contexto
- أنا أكتب الدرس وهي تقرأ الكتاب. (*anā aktubu d-dars wa-hiya taqraʾu l-kitāb.*) Yo escribo la lección y ella lee el libro.

**Explicación:** أكتب (prefijo أ, yo) y تقرأ (prefijo ت, ella).
