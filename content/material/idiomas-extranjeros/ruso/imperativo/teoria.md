# El imperativo en ruso (nivel B1)

## Introducción
El imperativo ruso se forma a partir de la **2.ª persona del presente** (o del futuro perfectivo). Tiene forma para **ты** y forma para **вы** (cortesía y plural), y usa el aspecto verbal para distinguir peticiones puntuales de instrucciones generales.

## Explicación central
- **Formación (ты)**:
  - raíz vocálica → **-й**: читать → **читай**, делать → **делай**, знать → **знай**;
  - raíz consonántica con **acento en la terminación** → **-и**: говорить → **говори**, писать → **пиши**, идти → **иди**, смотреть → **смотри**;
  - raíz consonántica con **acento en la raíz** → **-ь**: ответить → **ответь**, встать → **встань**.
- **Вы / plural**: + **-те**: читайте, говорите, идите.
- **Irregulares**: пить → **пей**, есть → **ешь**, дать → **дай**, быть → **будь**, ехать → **поезжай**.
- **Negativo**: **не** + imperfectivo: **Не читай**, **Не говорите**, **Не открывай окно** (no *не открой*).
- **Aspecto**: perfectivo para una petición puntual (**Открой** окно), imperfectivo para hábito o instrucción general (**Пиши** каждый день).
- **Cortesía**: **пожалуйста**; вы en lugar de ты.
- **Otros**: **давай(те)** + verbo perfectivo o infinitivo (*vamos a…*): Давай пойдём.

## Errores comunes de hispanohablantes
1. **Usar el infinitivo** como orden.
2. **Confundir -и y -ь** (*встани* ✗).
3. **Usar perfectivo con не** (*не открой*).
4. **Usar ты con desconocidos** (mejor вы).

## Comparación con el español
El español distingue imperativo afirmativo y subjuntivo negativo (*lee / no leas*); el ruso usa el mismo imperativo con *не*, pero elige el aspecto imperfectivo.

## Ejemplo extendido en contexto
- Читай книгу каждый день! Не открывай окно, пожалуйста. Скажи мне правду. Говорите медленнее, пожалуйста.

**Explicación:** читай (ты), не открывай (imperfectivo con не), скажи (perfectivo), говорите (вы).
