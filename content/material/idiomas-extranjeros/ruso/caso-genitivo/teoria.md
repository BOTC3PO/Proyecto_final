# El caso genitivo en ruso (nivel A2)

## Introducción
El **genitivo** (родительный падеж) responde a **кого? чего?** (*de quién, de qué*). Expresa **posesión**, **ausencia** (*нет*), **cantidad** (*много, мало*), origen y se usa tras muchas preposiciones (*у, из, от, для, без, до, после*).

## Explicación central
- **Formación (singular)**:
  - masculino: consonante + **-а**, -ь / -й → **-я**: стол → **стола**, учитель → **учителя**;
  - femenino: -а → **-ы** (-и tras г, к, х, ж, ч, ш, щ), -я → **-и**, -ь → **-и**: школа → **школы**, книга → **книги**, неделя → **недели**, дверь → **двери**;
  - neutro: -о → **-а**, -е → **-я**: окно → **окна**, море → **моря**.
- **Posesión**: дом **мамы**, книга **брата**.
- **Ausencia**: **нет** + genitivo: У меня **нет книги**; В комнате **нет стола**.
- **Tener**: **У** меня **есть** брат = tengo un hermano; У **брата** есть машина.
- **Preposiciones**: **из школы**, **от друга**, **для мамы**, **без сахара**, **до дома**, **после урока**.
- **Cantidad**: **много** времени, стакан **воды**, бутылка **молока**.
- **Genitivo plural**: -ов (m.), sin terminación en -а femenino (книга → **книг**), -ей tras ь.

## Ampliación
- **Genitivo plural**: masculino **-ов** (столов), **-ей** tras ж, ч, ш, щ y ь (ножей, карандашей, учителей); femenino y neutro sin terminación (книга → книг, окно → окон), **-ей** tras ь (дверь → дверей) y **-ий** en -ие (здание → зданий).
- **Genitivos irregulares**: друг → друзей, ребёнок → детей, человек → людей.
- **Cuantificadores**: много, мало, несколько, сколько: много книг, мало времени, несколько дней.
- **Fechas**: la fecha usa el genitivo para el mes: пятое января.
- **Más preposiciones**: около дома, у окна, из-за дождя, после урока, до вечера.
- **Ausencia en pasado y futuro**: Не было времени; Не будет денег (el verbo queda en neutro singular).
- **Preguntas**: Чей это дом? — Это дом брата. Кого нет дома? Чего нет в комнате?

## Errores comunes de hispanohablantes
1. **Usar nominativo tras нет**: *нет книга*.
2. **Traducir «tener» con un verbo** (*я имею*): se dice *у меня есть*.
3. **Confundir el genitivo con el plural nominativo** (*книги*).
4. **Olvidar la regla de las siete letras**.

## Comparación con el español
El español usa la preposición *de* para la posesión; el ruso usa la forma del caso (*дом мамы*). «Tener» se expresa con una construcción de posesión con preposición *у*.

## Ejemplo extendido en contexto
- У брата есть машина, но нет времени. Я иду из школы домой и покупаю стакан воды для мамы.

**Explicación:** у брата (poseedor), нет времени (ausencia), из школы, для мамы, стакан воды.
