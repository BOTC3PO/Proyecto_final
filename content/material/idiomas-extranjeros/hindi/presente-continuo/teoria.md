# El presente continuo en hindi (nivel A2)

## Introducción
El **presente continuo** expresa una acción **en curso ahora**. Se forma con la **raíz del verbo + रहा/रही/रहे + auxiliar होना**. El género y el número del sujeto se marcan en **रहा (m.)**, **रही (f.)**, **रहे (pl./respeto)**.

## Explicación central
- **Formación**: raíz + **रहा / रही / रहे** + **हूँ / है / हो / हैं**.
- **Paradigma (पढ़ना)**:
  | Persona | masc. | fem. |
  |---|---|---|
  | मैं | पढ़ रहा हूँ | पढ़ रही हूँ |
  | तुम | पढ़ रहे हो | पढ़ रही हो |
  | आप | पढ़ रहे हैं | पढ़ रही हैं |
  | वह | पढ़ रहा है | पढ़ रही है |
  | हम / वे | पढ़ रहे हैं | पढ़ रही हैं |
- **Ejemplos**: वह खा रही है (ella está comiendo), मैं जा रहा हूँ, हम चाय पी रहे हैं, वह खाना बना रही है.
- **Contraste con el habitual**: मैं पढ़ता हूँ (leo, habitualmente) frente a मैं पढ़ रहा हूँ (estoy leyendo ahora).
- **Negación**: **नहीं** antes del verbo: मैं नहीं पढ़ रहा हूँ.
- **Preguntas**: क्या तुम पढ़ रहे हो? तुम क्या कर रहे हो? तुम कहाँ जा रहे हो?
- **Marcador**: **अभी** (ahora mismo).

## Errores comunes de hispanohablantes
1. **Usar -ता para acciones en curso**.
2. **No concordar रहा/रही/रहे** con el sujeto.
3. **Omitir el auxiliar** होना.
4. **Confundir रहना** (vivir/quedarse) con el auxiliar रहा.

## Comparación con el español
El español usa *estar + gerundio*; el hindi usa la raíz + रहा/रही/रहे + auxiliar y marca el género del sujeto.

## Ejemplo extendido en contexto
- वह अभी सो रहा है और उसकी माँ खाना बना रही है। बच्चे खेल रहे हैं। (*vah abhī so rahā hai aur uskī māṃ khānā banā rahī hai. bachche khel rahe haiṃ.*)

**Explicación:** रहा (m.), रही (f.), रहे (pl.).
