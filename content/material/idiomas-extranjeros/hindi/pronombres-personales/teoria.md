# Pronombres personales en hindi (nivel A1)

## Introducción
El hindi distingue **tres grados de respeto** en la 2.ª persona (**तू, तुम, आप**) y usa el mismo pronombre para *él* y *ella*. El verbo **होना** (ser/estar) concuerda con el sujeto: **हूँ, है, हो, हैं**.

## Explicación central
| Persona | Hindi | Significado |
|---|---|---|
| 1.ª sing. | **मैं** | yo |
| 2.ª sing. | **तू** (muy íntimo), **तुम** (informal), **आप** (formal) | tú / usted |
| 3.ª sing. | **वह** (lejano) / **यह** (cercano) | él, ella, eso |
| 1.ª pl. | **हम** | nosotros |
| 3.ª pl. | **वे / ये** | ellos, ellas |

- **होना** en presente: मैं **हूँ**, तू **है**, तुम **हो**, आप **हैं**, वह **है**, हम **हैं**, वे **हैं**.
- **Sin género**: वह = él o ella; el verbo o el adjetivo muestran el género.
- **Respeto**: आप + **हैं** (plural de respeto).
- **Posesivos** (concuerdan con el sustantivo poseído): **मेरा / मेरी / मेरे** (mi), **तुम्हारा**, **आपका / आपकी / आपके**, **उसका**, **हमारा**, **उनका**: मेरा घर (m.), मेरी किताब (f.), आपका नाम, हमारा घर.
- **Ejemplos**: मैं छात्र हूँ (soy estudiante, m.); आप कैसे हैं? (¿cómo está usted?).

## Errores comunes de hispanohablantes
1. **Usar तू con desconocidos**.
2. **Concordar el posesivo con el poseedor** en lugar del objeto poseído.
3. **Conjugar होना mal** (*आप है*).
4. **Buscar «él/ella»** distintos.

## Comparación con el español
El español distingue *tú/usted*, pero el hindi tiene tres grados; los posesivos hindi concuerdan con el objeto poseído (*मेरा घर / मेरी किताब*).

## Ejemplo extendido en contexto
- आप कैसे हैं? मैं ठीक हूँ। यह मेरा घर है और वह आपकी किताब है। (*āp kaise haiṃ? maiṃ ṭhīk hūṃ. yah merā ghar hai aur vah āpkī kitāb hai.*)

**Explicación:** आप हैं (respeto), मैं हूँ, मेरा (m.), आपकी (f.).
