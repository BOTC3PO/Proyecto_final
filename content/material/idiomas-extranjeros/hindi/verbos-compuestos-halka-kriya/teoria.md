# Verbos compuestos (संयुक्त क्रिया) en hindi (nivel B1)

## Introducción
El hindi forma muchos **verbos compuestos**: un **verbo principal en raíz** seguido de un **verbo auxiliar o «vector»** que se conjuga y aporta matices de aspecto, intención o actitud. No cambian el significado básico, sino la **perspectiva** de la acción.

## Explicación central
- **Estructura**: raíz + vector conjugado: **खा** + **लेता हूँ** → खा लेता हूँ.
- **Vectores frecuentes**:
  | Vector | Matiz | Ejemplo |
  |---|---|---|
  | **जाना** | completar, cambio de estado | उठ जाना (levantarse), बैठ जाना (sentarse) |
  | **लेना** | beneficio propio | खा लेना (comérselo) |
  | **देना** | beneficio de otros | दे देना, बता देना |
  | **पड़ना** | súbito, involuntario | रो पड़ना (echarse a llorar), गिर पड़ना |
  | **डालना** | de un tirón, con fuerza | पढ़ डालना |
  | **रहना** | continuidad | करते रहना |
  | **बैठना** | error, imprudencia | कर बैठना |
  | **उठना** | súbito | चीख़ उठना |
- **चुकना** (ya): मैं खा **चुका** हूँ (ya he comido).
- **सकना** (poder): मैं आ **सकता** हूँ (puedo venir).
- **Conjugación**: solo el vector: वह रो **पड़ा**; उसने पूरी किताब पढ़ **डाली**.
- **Uso**: aporta naturalidad; su omisión puede sonar «neutra» pero menos idiomática.

## Errores comunes de hispanohablantes
1. **Conjugar ambos verbos**.
2. **Usar el vector equivocado** (देना/लेना).
3. **Olvidar चुकना** para «ya».
4. **Ignorar el matiz** de completitud (जाना).

## Comparación con el español
El español expresa estos matices con perífrasis (*acabar de, ponerse a, echarse a*); el hindi los codifica con vectores.

## Ejemplo extendido en contexto
- वह रो पड़ा और बैठ गया। मैंने खाना खा लिया है और मैं जा सकता हूँ। (*vah ro paṛā aur baiṭh gayā. maiṃne khānā khā liyā hai aur maiṃ jā saktā hūṃ.*)

**Explicación:** रो पड़ना (súbito), बैठ गया (completitud), खा लिया (para sí), जा सकता (capacidad).
