# Conectores de párrafo en chino (HSK 3-4)

## Introducción
Los conectores enlazan ideas y estructuran un texto: secuencia, causa, contraste, adición, condición y conclusión. Muchos funcionan en pares (因为…所以…).

## Explicación central
- **Secuencia**: 首先 … 然后 … 最后; 接着 (a continuación); 于是 (entonces).
- **Causa y consecuencia**: 因为 … 所以 …; 由于 … 因此 …; 因此 (por lo tanto).
- **Contraste**: 但是, 不过 (más suave), 然而 (formal); 虽然 … 但是 …; 尽管 … 还是 …
- **Adición**: 而且; 不但 … 而且 …; 另外, 此外 (formal); 既 … 又 …
- **Condición**: 如果 … 就 …; 只要 … 就 … (suficiente); 只有 … 才 … (única condición); 除非 … 才 …
- **Simultaneidad**: 一边 … 一边 …
- **Alternativa/preferencia**: 与其 … 不如 …
- **Concesión total**: 无论 … 都 …
- **Advertencia**: 否则 (de lo contrario).
- **Conclusión y ejemplo**: 总之; 例如.
- **Oposición**: 相反.

## Ampliación
### Organización de un texto en tres bloques
- **Introducción**: presenta tema y objetivo. 近年来…, 随着…的发展…, 众所周知… («como todos saben»).
- **Desarrollo**: ordena y conecta ideas.
- **Conclusión**: 总之, 总而言之, 综上所述, 由此可见.

### Conectores de ordenación
首先 → 其次 → 再次 → 最后 (primero, segundo, tercero, por último). También: 第一, 第二, 第三; 一方面…另一方面….

### Conectores de relación lógica
| Relación | Conectores |
|---|---|
| Causa | 因为, 由于, 之所以…是因为… |
| Consecuencia | 因此, 所以, 因而, 于是, 结果 |
| Contraste | 但是, 然而, 不过, 相反, 反而 |
| Adición | 而且, 另外, 此外, 不仅如此 |
| Concesión | 虽然…但是, 尽管…还是, 即使…也 |
| Condición | 如果…就, 只要…就, 只有…才, 除非…否则 |
| Ejemplo | 比如, 例如, 以…为例 |
| Reformulación | 也就是说, 换句话说, 简单来说 |
| Tiempo | 同时, 与此同时, 后来, 此后, 随后 |

### Conectores de registro
- **Oral**: 所以, 但是, 还有, 对了.
- **Escrito formal**: 因此, 然而, 此外, 综上所述.
- **Intermedio**: 不过, 而且, 另外.

### Conectores que cambian el rumbo
- **其实 / 事实上**: «en realidad»: matizan o corrigen.
- **不过**: «sin embargo», más suave que 但是.
- **相反**: «al contrario».
- **反而**: «en cambio, paradójicamente»: *他没生气，反而笑了.*

### Cómo evitar un uso pobre
1. No encadenes 因为…所以… en todas las frases: variá con 由于, 因此.
2. Un conector necesita su contraparte (虽然…但是, 不但…而且).
3. Usá recursos de cierre solo al final.

### Ejemplo de párrafo
*首先，运动对健康有好处。其次，它能减轻压力。此外，运动还能帮助人们认识新朋友。因此，我们应该每天锻炼。*

## Errores comunes de hispanohablantes
1. **Usar 因为 sin 所以** cuando se quiere marcar la relación: no es incorrecto, pero se espera el par; **no combinar** 虽然 con 因为.
2. **Confundir 只要 … 就 … con 只有 … 才 …**: suficiencia vs. exclusividad.
3. **Omitir 但是/还是 en el segundo miembro**: ❌ *虽然很累，他在工作* ✅ *虽然很累，但是他在工作*.
4. **Repetir 然后 excesivamente** en textos escritos: usar 接着, 随后, 于是.

## Comparación con el español
El español admite "aunque" o "pero" por separado; el chino tiende a las parejas correlativas (虽然…但是). Los conectores formales (然而, 因此, 此外) pertenecen al registro escrito.

## Ejemplo extendido en contexto
> 首先，我们要制定计划。然后，按照计划行动。虽然过程很难，但是只要坚持，就一定会成功。总之，努力最重要。

**Explicación:** 首先/然后 (secuencia), 虽然…但是 (concesión), 只要…就 (condición suficiente), 总之 (conclusión).
