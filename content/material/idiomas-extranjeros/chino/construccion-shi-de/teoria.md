# La construcción 是…的 (HSK 2)

## Introducción
Cuando ya sabemos que algo pasó y queremos preguntar o precisar **cuándo, dónde, cómo, con quién o quién** lo hizo, el chino usa la construcción **是…的**. No informa el hecho (eso lo hace 了), sino el detalle que se enfatiza. Es una de las estructuras más prácticas del nivel HSK 2.

## Explicación central
- **Forma básica**: S + 是 + [elemento enfatizado] + V + 的. 我是昨天来的。 «Vine ayer (no antes).»
- **Qué se puede enfatizar**: tiempo (昨天), lugar (在北京), medio (坐飞机), compañía (跟朋友), agente (是他做的), finalidad (为了学习).
  - 你是什么时候来的？ — 我是昨天来的。
  - 你是在哪儿学的汉语？ — 我是在北京学的。
  - 你是怎么来的？ — 我是坐地铁来的。
  - 这个蛋糕是谁做的？ — 是我妈妈做的。
- **Negación**: 不 va delante de 是: 我不是昨天来的，是今天来的。
- **Con objeto**: 我是昨天买的这本书。 o 我是昨天买这本书的。 (ambas)
- **Omisión de 是**: en afirmativas el 是 se omite con frecuencia: 我昨天来的。 En negativas y en preguntas con 是 explícito es obligatorio.
- **Sin 了**: en esta estructura no suele aparecer 了 en el mismo verbo: 我是昨天来的 (no 我是昨天来了的).
- **Solo para hechos pasados o conocidos**: 我是明天来的 ✗ (el futuro se expresa de otra manera).

## 了 vs. 是…的
| | 了 | 是…的 |
|---|---|---|
| Función | Informa que algo ocurrió | Precisa un detalle de algo ya sabido |
| Pregunta típica | 你去了吗？ | 你是什么时候去的？ |

## Ampliación
### Cuándo usar 是…的
Se usa para **pedir o dar un detalle de un hecho ya sabido**: ya se sabe que la persona vino, comió o compró, y se pregunta cuándo, dónde, cómo, con quién o por qué.
- *你是什么时候到的？ — 我是昨天到的.*
- *你是在哪儿买的？ — 我是在网上买的.*
- *你们是怎么认识的？ — 我们是通过朋友认识的.*
- *你是跟谁一起去的？ — 我是跟同学一起去的.*
- *你是为什么来的？ — 我是为了学习来的.*

### Con objeto
Si el verbo tiene objeto, hay dos órdenes: *我是昨天买的这本书.* / *我是昨天买这本书的.* Con pronombres el objeto va antes de 的: *我是昨天见他的.*

### 是…的 para describir
También sirve para dar una **característica**: *这个孩子是很聪明的.* *他是不会骗人的.* (Él no engaña: una afirmación de carácter.)

### Diferencias con 了
| 是…的 | 了 |
|---|---|
| Se centra en un detalle | Anuncia que ocurrió |
| *我是坐火车来的* | *我坐火车来了* |
| Contexto compartido | Información nueva |
| No se usa para hechos futuros | Se usa en cualquier tipo de hecho realizado |

Un buen reflejo: primero se confirma el hecho con 了, luego se pregunta el detalle con 是…的.
A: *你去北京了吗？* B: *去了.* A: *你是什么时候去的？* B: *我是去年夏天去的.*

### Negación y respuesta corta
- *你是坐飞机来的吗？ — 不是，我是坐火车来的.*
- *不是…，而是…* aclara la corrección: *我不是昨天来的，而是今天来的.*

### Errores a evitar
1. Usar el futuro: *我是明天来的* ✗.
2. Duplicar 了: *我是昨天来了的* ✗.
3. Olvidar 是 en negativas: *我不昨天来的* ✗ → *我不是昨天来的.*

## Errores comunes de hispanohablantes
1. **Usar 了 en lugar de 是…的**: preguntar «¿cuándo viniste?» con 了 suena raro.
2. **Poner 的 antes del verbo**: 我是昨天的来 ✗.
3. **Aplicarlo al futuro**.
4. **Olvidar 是 en la negación**.

## Comparación con el español
El español resuelve el énfasis con entonación o hendidas: «Fue ayer cuando vine». El chino tiene una estructura fija.

## Ejemplo extendido en contexto
A：你是哪年来中国的？B：我是2020年来的。A：你是跟谁一起来的？B：我是跟朋友一起来的。A：你是坐飞机来的吗？B：不，我不是坐飞机来的，是坐火车来的。
