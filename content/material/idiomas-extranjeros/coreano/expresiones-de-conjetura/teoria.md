# Expresiones de conjetura en coreano (intermedio-alto)

## Introducción
Para hablar de lo que no se sabe con certeza, el coreano usa terminaciones y adverbios que gradúan la seguridad del hablante. La elección depende de si la suposición se basa en evidencia visible, en lógica o solo en intuición.

## Explicación central
- **Adverbios**: 분명히 (sin duda) > 아마(도) (probablemente) > 어쩌면 (tal vez).
- **-(으)ㄹ 것 같다**: 'parece que…' (impresión), también con -(으)ㄴ/는 것 같다 para presente/pasado. *하늘이 어두워서 비가 올 것 같아요.*
- **-(으)ㄹ 거예요 / -겠-**: conjetura firme o basada en lo que se ve. *저 구름을 보니 곧 비가 오겠어요.*
- **-(으)ㄹ지도 모르다**: 'puede que…' (baja certeza). *길이 막혀서 늦을지도 몰라요.*
- **-나 보다 / -(으)ㄴ가 보다 / -(으)ㄴ 모양이다**: conclusión a partir de evidencia. *불이 꺼진 걸 보니 아무도 없나 봐요.*
- **-(으)ㄹ걸요**: suposición segura del hablante. *지금 집에 있을걸요.*
- **-(으)ㄹ 텐데**: expectativa con contraste: 'debería… pero…'.
- **-(으)ㄹ 리가 없다**: 'es imposible que…'.
- **-(으)ㄴ 듯하다**: 'parece que' (escrito, formal).

## Errores comunes de hispanohablantes
1. **Traducir "quizás" siempre por 아마**: 아마 implica bastante probabilidad; para poca, 어쩌면 o -(으)ㄹ지도 모르다.
2. **Usar -(으)ㄹ 것 같다 para hechos presentes**: para presente con verbo se usa -는 것 같다 (*비가 오는 것 같아요*).
3. **Confundir -(으)ㄹ 거예요 (conjetura) con futuro planificado**: *내일 비가 올 거예요* (predicción) frente a *내일 갈 거예요* (plan).
4. **Usar formas que no existen** como *-고 보니* como suposición: -고 보니 significa 'después de hacerlo, me di cuenta', no conjetura.

## Comparación con el español
El español usa el modo subjuntivo ("puede que llueva"), el futuro de conjetura ("estará en casa") y adverbios; el coreano no tiene subjuntivo, y expresa la conjetura con terminaciones específicas cuya elección depende del tipo de evidencia.

## Ejemplo extendido en contexto
- A: 민수 씨가 아직 안 왔네요.
- B: 길이 막히는 것 같아요. 아마 조금 늦을 거예요.
- A: 전화를 해 볼까요? 어쩌면 벌써 도착했을지도 몰라요.
- B: 그럴 리가 없어요. 아직 안 왔잖아요.

**Explicación:** -는 것 같아요 (impresión), 아마…-ㄹ 거예요 (probable), 어쩌면…-ㄹ지도 몰라요 (posible) y -ㄹ 리가 없어요 (imposible) recorren la escala de certeza.
