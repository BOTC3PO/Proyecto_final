# Hablar en coreano: nivel intermedio-bajo (B1)

## Introducción
En B1 se expresan opiniones, planes, motivos, peticiones y experiencias con estructuras de conexión y cortesía cotidiana (해요체).

## Explicación central
- **Petición**: -아/어 줄 수 있어요?, -아/어 주세요.
- **Permiso**: -아/어도 돼요?
- **Propuesta**: -(으)ㄹ까요?
- **Causa**: -아서/어서 (*늦어서 죄송해요*).
- **Opinión**: -다고 생각해요.
- **Experiencia**: -아/어 본 적이 있어요?
- **Plan**: -(으)ㄹ 거예요; **obligación**: -아/어야 돼요; **consejo**: -는 게 좋겠어요.
- **Comparación**: N보다; **condición**: -(으)면; **incapacidad**: 못 + verbo.
- **Rechazo cortés**: 괜찮아요, 미안해요 + motivo.

## Errores comunes de hispanohablantes
1. **Usar -지만 para causa** (*지하철이 고장 나지만 늦었어요*): es contraste; para causa, -아서/어서.
2. **Contestar 아니요 directamente**: suele suavizarse (*괜찮아요*, *좀 어려울 것 같아요*).
3. **Confundir 안 y 못.**
4. **Usar 거예요 para todo el futuro**: para promesas, -(으)ㄹ게요.

## Comparación con el español
El español usa el condicional o "por favor" para suavizar; el coreano usa terminaciones (-아/어 줄 수 있어요?) y fórmulas de agradecimiento y disculpa muy frecuentes.

## Ejemplo extendido en contexto
A: 펜 좀 빌려줄 수 있어요?
B: 네, 여기 있어요.
A: 감사합니다. 내일 같이 점심 먹을까요?
B: 미안해요. 내일은 바빠서 못 먹어요.

**Explicación:** petición, propuesta con -(으)ㄹ까요? y rechazo cortés con causa (-아서).
