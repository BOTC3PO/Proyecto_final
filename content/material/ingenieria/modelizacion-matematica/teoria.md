# Ingeniería — Modelización matemática (teoría)

## Tipo de teoría (si esto se carga al sistema)

**Presentación** — La modelización matemática es la herramienta clave para analizar y resolver problemas en ingeniería mediante representaciones simplificadas de sistemas reales.

---

## 1. ¿Qué es un modelo matemático?

Un modelo matemático es una **representación simplificada** de un sistema o fenómeno físico, químico, biológico u otros, expresado en términos de ecuaciones, variables y parámetros. Su objetivo no es replicar la realidad con exactitud absoluta —eso sería imposible—, sino capturar sus aspectos más relevantes para estudiar su comportamiento, hacer predicciones o diseñar soluciones técnicas. Por ejemplo, un modelo matemático del flujo de agua en una tubería ignora detalles microscópicos como las interacciones entre moléculas, pero sí describe cómo la presión y el caudal se relacionan a través de ecuaciones diferenciales.

## 2. Componentes esenciales de un modelo

Un modelo matemático se compone de tres elementos principales:  
- **Variables de estado**: Magnitudes que definen el comportamiento del sistema en un momento dado (ejemplo: temperatura, velocidad, posición). Son las incógnitas que se buscan resolver.  
- **Parámetros**: Valores constantes o coeficientes que describen características intrínsecas al sistema (ejemplo: conductividad térmica de un material, masa de un objeto).  
- **Incertidumbre**: Factores no controlables o datos imprecisos que afectan la precisión del modelo.  

Estos componentes interactúan mediante relaciones matemáticas que pueden ser algebraicas, diferenciales, estocásticas u otras según el contexto.

## 3. ¿Por qué los modelos son aproximaciones?

Un modelo nunca es una **copia exacta** de la realidad física. Si lo fuera, tendría tanta complejidad como el sistema mismo y no serviría para analizarlo ni tomar decisiones. Por ejemplo, un modelo que intentara predecir el clima incluiría millones de variables (temperatura, humedad, presión, etc.), pero en la práctica se simplifica seleccionando solo las más influyentes para lograr resultados útiles. La clave está en **equilibrar precisión y utilidad**: un modelo demasiado simple puede ser inútil; uno demasiado complejo, inviable.

## 4. Etapas del proceso de modelado

El proceso de creación de un modelo matemático sigue pasos estructurados:  
1. **Observación y definición del problema**: Identificar qué fenómeno se quiere estudiar y cuáles son las variables relevantes.  
2. **Abstracción**: Simplificar el sistema real, ignorando detalles no esenciales.  
3. **Formulación matemática**: Expresar las relaciones entre variables mediante ecuaciones o algoritmos.  
4. **Validación**: Comparar resultados del modelo con datos reales para ajustar parámetros o corregir errores.  
5. **Aplicación**: Usar el modelo para predecir comportamientos, optimizar procesos o guiar diseños técnicos.
