# Diseño gráfico — Preimpresión y producción gráfica (teoria)

> Tema de los finales de ruta de `oficios-orientacion-vocacional-PLANIFICACION.md`. Depende de `../teoria-del-color-y-paletas/` (ver `../dependencias.md`).

## Tipo de teoría (si esto se carga al sistema)

**Presentación** — varias secciones separables.

---

## 1. Del archivo al papel

La preimpresión es el conjunto de tareas que preparan un archivo para que pueda imprimirse bien. Es la etapa en la que se evitan errores que, una vez impresos, cuestan caros: textos cortados, imágenes borrosas, colores distintos de los esperados. Un archivo que se ve bien en la pantalla no necesariamente está listo para la imprenta.

Antes de empezar se habla con la imprenta: se le pregunta el formato final, el tipo de papel, el sistema de impresión, el sangrado, los márgenes y el tipo de archivo que recibe. Cada taller tiene sus requisitos, y muchas veces ofrece plantillas descargables.

## 2. Formato, sangrado y márgenes

El formato final es el tamaño de la pieza ya cortada. Como el corte nunca es perfecto, si hay fondos o imágenes que llegan hasta el borde, deben extenderse unos milímetros más allá del tamaño final: esa extensión se llama sangrado (bleed). Un valor habitual es de 3 mm por lado, aunque algunas imprentas piden 5 mm; se confirma con cada taller. Sin sangrado pueden aparecer bordes blancos al refilar.

El margen de seguridad es la franja interior donde no deben ubicarse textos ni elementos importantes, para que el corte no los afecte. Suele ser de varios milímetros adentro del formato final. Las marcas de corte indican por dónde se refila. En piezas plegadas se agregan además las marcas de plegado, y hay que considerar el grosor del papel en libros y revistas.

## 3. Color: CMYK, tintas planas y negros

Las impresiones comunes trabajan con CMYK. Se convierte el archivo desde RGB al perfil que indique la imprenta, y se revisan los colores después de la conversión, porque algunos tonos vivos cambian. Un color en pantalla nunca es una garantía del color impreso: para color crítico se pide una prueba de color.

Las tintas planas, como las del sistema Pantone, son tintas premezcladas que se usan para colores exactos de marca o que no se logran con CMYK. Se imprimen en una pasada propia y suelen costar más. En los negros, para el texto pequeño se usa negro solo (100 % K) y no una mezcla de las cuatro tintas, porque si las placas se desalinean levemente, las letras finas se ven con halos de color. Para grandes superficies negras se suele usar un negro enriquecido, pero hay que cuidar que la suma total de tinta no supere el límite que indique la imprenta.

## 4. Imágenes y resolución

Las imágenes de mapa de bits deben tener una resolución adecuada: para impresión se suele recomendar 300 píxeles por pulgada (ppp) al tamaño final. Una imagen de 72 ppp que se ve bien en pantalla se imprimirá pixelada. Agrandar artificialmente una imagen de baja resolución no mejora la calidad, porque solo se interpolan los píxeles. Las piezas que se ven de lejos, como una lona o un cartel grande, toleran resoluciones menores porque se miran a distancia.

Los logos y las ilustraciones vectoriales se escalan sin pérdida y son preferibles cuando se puede. Si una imagen incluye transparencias o sombras, se revisa cómo se comportan en el archivo final. Y las imágenes se incrustan o se entregan junto con el archivo para que no falten vínculos.

## 5. Entrega: PDF y verificación previa

El formato más usado para entregar a imprenta es el PDF, porque conserva el diseño en cualquier equipo. Muchas imprentas piden un PDF con una norma específica, como la familia PDF/X, pensada para impresión, con tipografías incrustadas, perfil de color definido y marcas de corte y sangrado. Se confirma cuál norma pide cada taller. Si se entrega un archivo abierto, hay que incluir las tipografías y los vínculos, o convertir los textos a curvas, y eso último impide editarlos después.

Antes de enviar se hace una verificación previa (preflight): se revisan tipografías incrustadas, resolución de imágenes, modo de color, sangrado y márgenes. Y se pide una prueba cuando el trabajo es importante. Son controles de minutos que evitan reimprimir un tiraje entero.
